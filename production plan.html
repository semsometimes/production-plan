📋 총괄생산계획(APP)이란?

제품군(Product Family) 단위의 중기(3~18개월) 생산계획입니다.

수요 예측을 기반으로 인력 수준, 재고량, 외주 여부 등을 결정하여 총 비용을 최소화합니다.

ERP에서는 "S&OP (Sales & Operations Planning)"이라고도 합니다.
🔢 목적함수 (비용 최소화)
Z = Σ[ 640·W_t ← 정규 노무비 + 6·O_t ← 초과근무비 + 300·H_t ← 고용비용 + 500·L_t ← 해고비용 + 2·I_t ← 재고유지비 + 5·S_t ← 부족재고비 + 10·P_t ← 재료비 + 30·C_t ← 하청비용 ]
※ 파라미터 변경 시 계수가 자동 재계산됩니다
📐 제약조건
노동력 균형: W_t = W_{t-1} + H_t - L_t 생산능력: P_t ≤ 40·W_t + (1/4)·O_t 재고 균형: I_t = I_{t-1} + P_t + C_t - D_t - S_{t-1} + S_t 초과근무 한도: O_t ≤ 10·W_t 초기: W₀=80명, I₀=1000개 최종: I_T≥500개, S_T=0
💡 LP vs IP 차이
LP (연속형): 소수점 허용 → 수학적 최솟값 제공. 계산 빠름.
IP (정수형): 정수만 허용 → "2.7명" 대신 "3명"처럼 현실적인 계획. 계산 느림.
